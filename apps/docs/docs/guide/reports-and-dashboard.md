# Reports & Dashboard

## The dashboard

The home screen, with seven widgets:

| Widget | Shows |
|---|---|
| Get started | The onboarding checklist (hides itself once completed) |
| Ticket volume | Tickets created per day, last 14 days |
| Open tickets by priority | How many open tickets sit at each priority level |
| SLA compliance | % of tickets resolved on time, last 90 days |
| Customer satisfaction | Average from [CSAT surveys](/guide/csat-surveys), last 90 days |
| Agent workload | Open tickets assigned to each agent, plus unassigned ones |
| Recent activity | The most recently touched tickets, with their current status |

Every agent can hide or reorder their own widgets by hovering over one —
the preference is saved **per person**, not per tenant, so two agents can
have completely different dashboards without stepping on each other.

## Reports

The same data feeding the dashboard is available as standalone reports
for deeper analysis — ticket volume over a wider date range, an SLA
compliance breakdown, and historical agent workload. It's the same
underlying data, presented without the dashboard's fixed "last 14/90
days" window.
